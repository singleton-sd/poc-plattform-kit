# DTO mapping

Wire DTOs for Nest responses use **`@poc-plattform-kit/dto-map`** plus a colocated
`*.mapper.ts` file. See [`packages/dto-map/README.md`](../packages/dto-map/README.md)
for the convention and the threshold to adopt a mapper library later.
